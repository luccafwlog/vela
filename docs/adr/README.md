# Architecture Decision Records

Índice revisado em 2026-10-13 pela [revisão geral da documentação](../archive/plans/2026-10-13-revisao-geral-documentacao.md),
conforme a [ADR 0082](./0082-governanca-documental-dono-unico-e-adr-historica.md).

Como ler:

- **Status** diz o que aconteceu com a decisão (definições em [Convenção](#convenção)).
  A linha `Status:` de cada ADR concorda com esta coluna, e o `npm run docs:check`
  confere isso.
- **Implementação** diz se o código cumpre a decisão. "Parcial" nomeia o que falta;
  as divergências decididas pelo dono em 2026-10-14 ([ADR 0083](./0083-decisoes-da-revisao-geral-da-documentacao.md)
  e [ADR 0085](./0085-modelo-de-permissoes-por-perfil.md)) têm a correção no [plano de correções](../archive/plans/2026-10-14-correcoes-decididas-na-revisao-geral.md).
- **Regra vigente em** aponta o documento que descreve a regra hoje. A ADR explica
  por que se decidiu; a regra por extenso fica no módulo.
- Toda ADR estendida ou supersedida abre com a faixa "Situação atual", que diz o que
  não vale mais. O texto original abaixo da faixa é preservado.
- Números de migration citados no texto original de ADRs anteriores à
  [ADR 0062](./0062-consolidacao-migrations-schema-1-0.md) costumam ser da cadeia
  arquivada (`supabase/migrations_archive/`); a faixa de cada ADR desambigua.

## Convenção

- **aceito**: decisão vigente; ressalvas de implementação devem ser explícitas;
- **estendida**: uma ADR posterior acrescenta escopo sem revogar parte da
  decisão;
- **supersedida parcialmente**: uma ADR posterior altera somente o aspecto
  indicado, preservando o restante da decisão;
- **substituída**: decisão integralmente substituída por outra identificada;
- **obsoleta**: decisão sem superfície executável atual;
- novas mudanças arquiteturais devem criar uma ADR ou atualizar explicitamente
  a relação de supersessão neste índice.
