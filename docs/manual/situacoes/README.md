# Catálogo de situações

Lista, por capítulo do Manual do Operador, dos objetivos de quem usa o Vela
("Quero fazer…") e das situações comuns fora do caminho normal
("Aconteceu…"). É a pauta da redação: cada procedimento do manual responde um
objetivo, e cada situação vira um quadro "Aconteceu…" no capítulo
([plano, "O manual parte do objetivo de quem usa"](../../plans/2026-10-26-manual-do-operador.md#o-manual-parte-do-objetivo-de-quem-usa)).

A [matriz de cobertura](../cobertura/) continua garantindo que nenhuma regra
fica sem lugar; o catálogo diz em que ordem e em que pergunta do usuário cada
regra aparece.

## Como cada situação é escrita

- **O que o sistema faz** — o comportamento visível, com os rótulos da tela.
- **Por quê** — a regra geral que explica o comportamento.
- **O que você faz** — os passos para chegar ao resultado, com quem pode fazer.
- **Regras** — os números da matriz que sustentam a resposta. Situação sem
  regra é pergunta ao código antes de virar texto.

O dono confere cada catálogo antes da redação do capítulo: marca o que é raro,
o que falta e o que precisa de exemplo.

Evidência: as situações foram montadas a partir das regras da matriz, que
foram lidas no código (sem execução). As respostas ainda serão executadas no
ambiente local pelos scripts de imagem da Etapa 2.
