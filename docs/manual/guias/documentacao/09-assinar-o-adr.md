A parte da Documentação são as seções **Carga descarregada** e **Vazios descarregados** de cada terminal.

::: tela adr-terminal
O ADR de um terminal.
:::

::: passos
1. Na ficha da Viagem, abra a aba **ADR**.
2. Clique no porto.
3. Escolha o terminal.
4. Em cada seção da Documentação, **Alterar** › **Confirmado** (ou **Nada a declarar**) › **Confirmar**.
5. Clique em **Assinar Documentação**.
:::

Número errado? Corrija na origem (o B/L, os **Vazios IMP**): o ADR mostra a correção.
