Suba os B/Ls pela própria Viagem: a **Importação rápida** já abre cada janela com a Viagem escolhida.

::: tela viagem-importacao-rapida
A Importação rápida, na aba Importação da ficha da Viagem.
:::

::: lado
1. Clique em **B/L container**.
2. Confira a Viagem em **Navio / Viagem**.
3. Escolha os arquivos: vários B/Ls de uma vez.
4. Na **Prévia**, confira **Cria** ou **Atualiza** em cada linha.
5. Clique em **Importar N B/Ls**.
::: tela importar-bl-previa
A prévia dos B/Ls.
:::
:::

**Carga solta:** o mesmo caminho, por **Manifesto BB** ou **B/L carga solta**.

::: sozinho
- O Cliente é vinculado pelo CNPJ. CNPJ que ainda não é Cliente vai para a Revisão (etapa 3).
- As Taxas Locais são calculadas na hora. A fatura espera o CE (etapa 6).
:::
