O Baplie vem antes dos B/Ls: cada B/L importado depois já entra com as marcas IMO e OOG do Baplie, e as Taxas Locais já são calculadas com elas.

::: lado
1. Em **Baplie EDI**, escolha a Viagem.
2. Clique em **Importar Baplie EDI**.
3. Confira a **Viagem de destino** e escolha o arquivo.
4. Deixe marcados os portos desta operação.
5. Clique em **Importar N containers**.
::: tela baplie-previa
A prévia do Baplie.
:::
:::

::: sozinho
- O Baplie não cria B/L. A conferência com os B/Ls começa quando eles entram (etapa 5).
- Porto que ainda não é escala aparece desmarcado: se o navio vai mesmo a ele, crie a escala (etapa 1).
:::
