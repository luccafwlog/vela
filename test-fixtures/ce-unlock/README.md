# Exemplo de planilha ZPT — Desbloqueio de CE

`zpt-five-columns-example.xlsx` foi gerado pela Edge Function real executada em
Deno, com autenticação/HTTP simulados pelo shim local e banco PostgreSQL local.
O BL `CE557-A` é fictício. Cinco colunas: BL, Termo, Procuração, Entrega de BL,
Pagamento das taxas. Os quatro indicadores são Sim/Não; não inclui CE ou VIP.

A amostra valida o formato técnico; **não representa homologação pela ZPT**.
